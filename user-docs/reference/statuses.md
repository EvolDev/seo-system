# Статусы

В скобках — код статуса. Его видно в выгрузках и фильтрах.

## Площадка

Статус у площадки свой для каждого продукта. Одна и та же площадка
может быть одобрена для Convertio и отклонена для продукта из другой
ниши. Список площадок и карточка показывают статус для выбранного
продукта — [Как найти площадку и отфильтровать
список](../how-to/find-sites.md). Сменить статус — щелчок по нему в
**Площадках**: откроется окно с выбором статуса и причиной отказа.

Статусы идут в том же порядке, что в окне статуса, в фильтре **Статус**
и при сортировке по колонке **статус**: сначала путь площадки в работу,
потом отказы, последним — аудит.

| Статус | Значит |
|---|---|
| Новая (`new`) | для этого продукта ещё не смотрели |
| Просмотрено (`viewed`) | посмотрели, решения пока нет |
| Одобрена (`approved`) | можно размещаться, заявки ещё нет |
| Заявка отправлена (`ordered`) | заявка отправлена или статья уже в работе |
| Размещались (`placed`) | есть хотя бы одно опубликованное размещение этого продукта |
| Отбрасываю (`discarded`) | мы отказались от площадки; причина — в окне статуса и в истории заметок |
| Отказала площадка (`declined`) | площадка отказала нам — не взяла заявку или отказалась писать |
| Чёрный список (`blacklisted`) | для этого продукта не работаем, не предлагать снова. Чёрный список у всех продуктов сразу — площадка «заблокирована»: загрузки прайсов и каталога её пропускают ([Как загрузить прайс продавца](../how-to/upload-price-list.md#review)) |
| На аудите (`auditing`) | оценка идёт прямо сейчас |

До октября 2026 года был один статус «Отклонена» на оба отказа. Все
площадки с ним были нашим отказом («…отбрасываем») и стали
**Отбрасываю**, причины остались.

### Что меняется само {#auto}

Статус двигают размещения этого продукта на площадке:

- размещение получило **Заявка отправлена**, **Пишется** или **На
  проверке** — площадка становится **Заявка отправлена**;
- размещение получило **Опубликовано** — площадка становится
  **Размещались**.

Статус движется только вперёд по пути «Новая → Просмотрено → Одобрена →
Заявка отправлена → Размещались»: новая заявка на площадку, где уже
размещались, статус не откатывает. Новая заявка или публикация сильнее
прежнего решения **Отбрасываю**, **Отказала площадка** и **На аудите**:
раз заявку отправили, площадка снова в работе. **Чёрный список** сам не
меняется никогда.

Срабатывает только смена статуса размещения. Правка комментария или
адреса статьи, проверка индексации и повторная загрузка той же заявки из
таблицы статус площадки не трогают — поэтому отказ, поставленный после
заявки, остаётся.

Руками в окне статуса можно поставить любой статус.

Если на площадке уже есть размещение другого нашего продукта, карточка
это показывает — статус для текущего продукта от этого не меняется.

Площадки, пришедшие из таблицы без решения, получают для Convertio
статус «Новая» с пометкой «импортирована без решения». Пометка
снимается, как только по площадке принято решение — в таблице, в
админке или само, по размещению.

## Размещение

```
Запланировано → Заявка отправлена → Пишется → На проверке → Опубликовано
                                                          ↘ Отклонено
```

| Статус | Значит |
|---|---|
| Запланировано (`planned`) | площадка и анкор выбраны, заявки ещё нет |
| Заявка отправлена (`ordered`) | заявка на Collaborator создана |
| Пишется (`writing`) | статью готовит площадка или система |
| На проверке (`review`) | статья получена, идёт проверка |
| Опубликовано (`published`) | статья на площадке; система следит за индексацией и ссылками |
| Отклонено (`rejected`) | площадка или мы отказались |
| Отменено (`cancelled`) | заявку сняли до публикации |

Размещения не удаляются: отменённое остаётся в истории со статусом
«Отменено».

Анкор в статусах от «Запланировано» до «На проверке» считается **в
ожидании**, в «Опубликовано» — **размещённым**.

## Статья

| Статус | Значит |
|---|---|
| Черновик (`draft`) | создан, ещё не проверялся |
| Проверяется (`validating`) | идут автоматические проверки |
| На доработке (`revising`) | система правит проваленные пункты |
| Нужно решение (`needs_human`) | автоматическая доработка не помогла, статья ждёт вас |
| Принята (`accepted`) | вы одобрили текст |
| Отклонена (`rejected`) | текст не подошёл |

Сколько кругов доработки система делает сама — на странице
[Пороги и ориентиры](thresholds.md).
