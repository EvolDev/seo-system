# Статусы

В скобках — код статуса. Его видно в выгрузках и фильтрах.

## Площадка

| Статус | Значит |
|---|---|
| Новая (`new`) | ещё не оценивалась |
| На аудите (`auditing`) | оценка идёт прямо сейчас |
| Одобрена (`approved`) | можно размещаться; сюда же попадают площадки с отправленной заявкой |
| Отклонена (`rejected`) | причина — в карточке площадки |
| Размещались (`placed`) | есть хотя бы одно опубликованное размещение под Convertio |
| Чёрный список (`blacklisted`) | не работаем, не предлагать снова |

Старые размещения под Clideo статус площадки не меняют.

Площадки, перенесённые из Excel без решения, получают статус «Новая» с
пометкой «импортирована без решения». Так их видно отдельно от
действительно новых.

## Размещение

```
Запланировано → Заявка отправлена → Пишется → На проверке → Опубликовано
                                                          ↘ Отклонено
```

| Статус | Значит |
|---|---|
| Запланировано (`planned`) | площадка и анкор выбраны, заявки ещё нет |
| Заявка отправлена (`ordered`) | заявка на Collaborator создана |
| Пишется (`writing`) | статью готовит площадка или система |
| На проверке (`review`) | статья получена, идёт проверка |
| Опубликовано (`published`) | статья на площадке; система следит за индексацией и ссылками |
| Отклонено (`rejected`) | площадка или мы отказались |
| Отменено (`cancelled`) | заявку сняли до публикации |

Размещения не удаляются: отменённое остаётся в истории со статусом
«Отменено».

Анкор в статусах от «Запланировано» до «На проверке» считается **в
ожидании**, в «Опубликовано» — **размещённым**.

## Статья

| Статус | Значит |
|---|---|
| Черновик (`draft`) | создан, ещё не проверялся |
| Проверяется (`validating`) | идут автоматические проверки |
| На доработке (`revising`) | система правит проваленные пункты |
| Нужно решение (`needs_human`) | автоматическая доработка не помогла, статья ждёт вас |
| Принята (`accepted`) | вы одобрили текст |
| Отклонена (`rejected`) | текст не подошёл |

Сколько кругов доработки система делает сама — на странице
[Пороги и ориентиры](thresholds.md).
