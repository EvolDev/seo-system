# Как загрузить список размещений

Размещения другого продукта часто живут в файле коллеги: где разместились,
через какого продавца, за сколько, с какими анкорами. После загрузки они в
базе: у размещений продукта — продавец, сотрудник, адрес статьи, анкоры и
ссылки, дата, цена и отметки индексации. Площадки, которых не было,
появляются в базе; в **Площадках** другого продукта у них видно **другие
продукты**, а у площадок без рабочей цены — цена продавца, через которого
брали. Все площадки файла попадают в рабочий список «‹продукт› ·
размещения · ‹дата›».

## Перед началом

- Продукт заведён: **Справочники → Продукты**.
- Файл — xlsx или csv. Хватит и одного столбца доменов — с заголовком
  («Сайт», «Target») или без него.
- Тот же файл можно загружать снова — с новыми строками и исправленными
  старыми: загрузка дополнит, а не задвоит.

## Шаги

1. Откройте **Работа → Загрузки → Загрузить файл**. В **Что загружаем**
   выберите **Размещения продукта**. В следующий раз форма откроется с
   этим типом сама, а продукт в ней — всегда рабочий, из шапки.
2. В **Продукт** выберите, чьи это размещения.
3. Если файл от продавца — выберите его в **Продавец** или впишите нового.
   Если от сотрудника — выберите в **Сотрудник** или впишите нового: он
   заведётся без права входа. Продавец и сотрудник подставятся в строки,
   где в файле нет своей колонки. Можно оставить пустыми.
4. **Дата файла** — на неё запишутся отметки индексации из колонки без
   даты в заголовке, по ней назовётся рабочий список. Выберите файл и
   нажмите **Дальше**.
5. Откроются колонки. Поле угадывается по заголовку: «Target» — площадка,
   «Person» — сотрудник, «Source» — продавец, «Анкор1» и «Ссылка1» —
   первая ссылка, «Итог цена» — заплачено. Проверьте выпадающие списки,
   особенно с пометкой **похоже — проверьте**, и нажмите **Дальше:
   сводка**. Следующий файл с теми же колонками этот шаг пропустит, про
   новую колонку спросит только её.
6. Через несколько секунд откроется сводка: сколько размещений будет
   создано, дополнится и уже есть; новые продавцы и сотрудники; что
   исправлено и что вызывает сомнения — списками с номерами строк.
   Нажмите **Записать в базу**.

!!! tip
    Колонки без своего поля идут в **Прочие данные** — их видно в панели
    размещения, из файла ничего не теряется. Метрики площадки из такого
    файла (Traffic, DR, Top Geo) — тоже туда: когда их сняли, неизвестно,
    а в **Площадках** показываются свежие замеры.

## Как загрузка понимает файл

- **Какое размещение дополнить.** Сначала — с той же статьёй: адреса
  сравниваются без `www.`, `/` в конце, `#…` и меток вроде `utm_`. Иначе —
  единственное размещение продукта на площадке без адреса статьи: адрес
  ему и достанется. Строка без адреса — единственное размещение продукта
  на площадке. Не нашлось — создаётся новое.
- **Найденное только дополняется.** Пустое заполняется, статус двигается
  только вперёд. Что в базе заполнено по-другому — дата, цена, продавец,
  сотрудник, тип, ссылки — в списке **Расходится с базой**. Если файл
  свежее базы, нажмите **Записать, заменив расходящиеся**: возьмутся
  значения из файла. Статус назад не идёт никогда. **Заплачено** из счёта
  продавца (в списке — с пометкой «из счёта») не заменяется: его меняют в
  самом счёте — [Как вести счета продавцов](invoices.md).
- **Пустой статус** — **Опубликовано**: файл — список того, что уже сделано.
- **Анкор и ссылка, перепутанные местами**, исправляются сами: ссылка — то,
  что похоже на адрес, а из двух адресов — тот, что на домене продукта.
  Ссылка не на домен продукта (например, в App Store) записывается и
  видна в сводке. Вместо адреса текст — такая ссылка не записывается.
- **«Link insert» в комментарии** — это тип размещения **вставка ссылки**.
  Остальные комментарии — заметки площадки с продуктом; тот же текст
  второй раз не пишется.
- **Цена.** **Заплачено** — у размещения. Она же становится ценой
  продавца на дату размещения: у площадки без рабочей цены — рабочей, а
  где рабочая уже есть — рядом, для справки, без вопроса «ждёт решения».
  У Collaborator цен из размещений нет: его цены приходят с каталогом.
- **Три цифры после разделителя** — «197.393» или «241,258» — это евро и
  центы с лишней цифрой: загрузка читает 197,39 и 241,26. В xlsx таблица
  такую цену уже превратила в 197 393 с разделителем разрядов — загрузка
  узнаёт её по формату ячейки; в выгрузке того же листа в csv формата нет,
  и роль запятой берётся из самого файла: если где-то стоит «311,81»,
  значит запятая десятичная. Каждая такая цена — в сводке, в списке **Три
  цифры после разделителя**: проверьте, особенно цены с двумя точками
  («4.330.755» → 4 330,76).
- **Цена, похожая на ошибку**, — больше порога из [Порогов и
  ориентиров](../reference/thresholds.md#upload-price-cap) — не
  записывается.
- **Даты.** Колонок с датой может быть две: **«Дата размещения»** — когда
  вышла статья, **«Дата отправки»** — когда заявка ушла вебмастеру. Каждая
  идёт в своё поле, пустая колонка оставляет поле пустым. Если колонка с
  датой одна, её раскладывает статус: у «Размещено» это дата публикации, у
  остальных — дата заявки.
- **Индексация.** Колонок может быть несколько: дата отметки — из
  заголовка («Индексация 02.09.26»), без неё — дата файла. Каждая
  отметка — проверка «человек» в истории проверок размещения. «В индексе»
  — по самой свежей проверке: старая отметка не перебивает более свежую
  проверку системы.
- **Продавцы** ищутся по имени без учёта регистра, **сотрудники** — по
  имени; новых заводит загрузка. Сотрудник появляется в **Настройки →
  Пользователи** без права входа: когда начнёт работать в системе сам,
  ему зададут пароль, и его размещения уже будут за ним.

## Результат

- **Размещения**: размещения продукта с продавцом, сотрудником, датой,
  суммой **Заплачено**, анкорами и ссылками; в панели — **Прочие данные
  из файла** и отметки индексации в **Проверки индексации**.
- **Площадки** другого продукта: у площадок файла — **другие продукты**,
  у новых для базы площадок — статус **Новая** и цена продавца.
- Статус площадки у этого продукта — **Размещено**; в истории статуса —
  «загрузка».
- Итог загрузки открывает **Площадки** с рабочим списком файла и список
  размещений продукта.

## Если что-то пошло не так

- **«… — не адрес статьи на …» в «Ошибках»** — адрес статьи не на домене
  площадки из этой строки. Строка не записана: поправьте файл и
  загрузите его снова.
- **«Похоже, это файл «…», а не «…»»** — в строках файла все ссылки ведут на
  другой ваш продукт. Такие строки не записываются, они перечислены в списке
  **Ссылки ведут на другой продукт — пропущены**. Если файл правда не того
  продукта, загрузите его заново, выбрав в шапке нужный продукт.
- **«Цена похожа на ошибку»** — цена в сотни раз больше обычной.
  Исправьте её в файле и загрузите снова — уже записанное не задвоится.
- **«Три цифры после разделителя» прочитаны не так** — например, «1.200» в
  файле значило тысячу двести. Поправьте цену в панели размещения или
  исправьте файл (запишите «1200») и загрузите его с **Записать, заменив
  расходящиеся**.
- **«Непонятная дата»** — дата записана не как «дд.мм.гггг», например
  «1.23.2026». Дата останется пустой: поправьте файл или впишите её в
  панели размещения.
- **«Неясно, какое размещение дополнить»** — у площадки несколько
  размещений продукта без адреса статьи. Впишите адрес в файле или в
  панели нужного размещения и загрузите файл снова.
- **«На площадке уже есть другая статья»** — у продукта на площадке есть
  статья с другим адресом; строка станет вторым размещением. Если адрес в
  файле — опечатка, поправьте его.
