# Как загрузить файл анкоров

Файл анкоров добавляет новые анкоры продукта, обновляет у знакомых адрес,
объёмы, раздел и тип страницы, дописывает позиции на даты из заголовков и
доли. Это **сведение**, а не замена: чего нет в файле, остаётся в системе;
пустая ячейка ничего не стирает.

## Перед началом

- Файл — xlsx или csv. Подойдёт вся таблица линкбилдинга: нужный лист
  система найдёт сама по заголовкам.
- В листе анкоров обязательны две колонки: анкор (**Keyword**) и куда он
  ведёт (**URL**). Остальное — если есть: **Volume**, **Global Volume**,
  **Tool**, **Type**, позиции **Pos 22.09.26**.

## Шаги

1. Откройте **Справочники → Анкоры** и нажмите **Загрузить файл анкоров** —
   тип и продукт уже выбраны. Или **Работа → Загрузки → Загрузить файл**,
   тип **Анкоры продукта**, и продукт.
2. Выберите файл и нажмите **Дальше**.
3. **Колонки файла.** Знакомые заголовки размечены сами. **Links Placed** и
   **Links Waiting** не загружаются — их система считает по размещениям.
   Позиций может быть сколько угодно: дата снимка — из заголовка.
   Разметка запомнится: следующий такой файл пройдёт без этого шага.
4. **Сводка до записи** — что произойдёт: новые анкоры, что изменится
   («было → станет»), сколько позиций, доли типов страниц, безанкорка,
   страны и замечания по строкам. В базу ещё ничего не записано.
5. Нажмите **Записать в базу**.

## Результат

Итог: сколько анкоров добавлено и обновлено, позиций записано, долей и
сколько старых ссылок получили анкор. **К анкорам** — страница анкоров
продукта с новыми данными.

Листы долей из той же книги разбираются сами, без разметки:

- **Распределение по типам страниц** — цель и деление на прямой /
  разбавленный / безанкор;
- **Распределение безанкорки** — бренд, адрес и нейтральные слова со своими
  процентами; старые ссылки «Convertio», «click here» получают этот анкор и
  начинают считаться в долях;
- **Распределение по странам**.

Тот же файл второй раз ничего не меняет.

## Если что-то пошло не так

- **«Укажите колонку с анкором…» / «…куда ведёт»** — на шаге колонок
  выберите их вручную.
- **«У позиции … нет даты в заголовке»** — переименуйте колонку в файле:
  «Pos 22.09.26».
- **Замечания** в сводке — строка без адреса, повтор анкора, не число в
  объёме. Строка с ошибкой пропускается, остальное записывается.
