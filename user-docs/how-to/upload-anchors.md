# Как загрузить файл анкоров

Файл анкоров добавляет новые анкоры продукта, обновляет у знакомых адрес,
объёмы, раздел и тип страницы, дописывает позиции на даты из заголовков и
доли. Файл — анкоры одного региона: они сводятся со [списком анкоров этого
региона](../reference/anchors.md#regions), а новый регион заводит новый список. В режиме **Дополнить список** отсутствующие остаются активными.
**Полный список** делает отсутствующие анкоры неактивными. Записи не удаляются;
пустая ячейка не стирает прежнее значение.

## Перед началом

- Файл — xlsx или csv. Подойдёт вся таблица линкбилдинга: нужный лист
  система найдёт сама по заголовкам.
- В листе анкоров обязательны две колонки: анкор (**Keyword**) и куда он
  ведёт (**URL**). Остальное — если есть: **Volume**, **Global Volume**,
  **Tool**, **Type**, позиции **Pos 22.09.26**.

## Шаги

1. Откройте **Справочники → Анкоры** и нажмите **Загрузить файл анкоров** —
   тип, продукт и регион открытого списка уже выбраны. Или **Работа →
   Загрузки → Загрузить файл**, тип **Анкоры продукта**, и продукт.
2. **Регион списка** — страна, чьи это анкоры. Сверху — регионы, у которых
   список уже есть (США), ниже — все страны: печатайте «браз» или «br».
   Новая страна — новый список, он появится при записи. Замеры из колонок
   «Pos …» запишутся по выдаче этой страны.
3. Выберите файл. Для отдельного списка безанкорки в **Состав файла анкоров**
   выберите **Все строки — безанкорные ссылки**. В **Обновление списка анкоров**
   выберите **Полный список — отключить отсутствующие анкоры**, если файл
   заменяет рабочий список; для частичного файла оставьте **Дополнить список**.
   Нажмите **Дальше**.
   **Определить по файлу** распознаёт безанкорку по колонкам
   **Anchor text / URL / %**; этот режим подходит и для всей книги.
4. **Колонки файла.** Знакомые заголовки размечены сами. **Links Placed** и
   **Links Waiting** не загружаются — их система считает по размещениям.
   Позиций может быть сколько угодно: дата снимка — из заголовка.
   Разметка запомнится: следующий такой файл пройдёт без этого шага.
   Состав файла можно изменить здесь же. Столбец с процентом назначьте как
   **Доля внутри безанкорки, %**; выбор поля включает загрузку этой колонки.
   Без столбца доли безанкорные типы всё равно сохраняются, прежние доли остаются.
5. **Сводка до записи** — регион и лист книги, из которого взяты анкоры,
   и что произойдёт: новые анкоры, что изменится
   («было → станет»), сколько **замеров** — место анкора в выдаче Google на
   дату каждой колонки «Pos …»: у анкора по замеру на дату, 969 анкоров и две
   колонки — 1938 замеров, — доли типов страниц, безанкорка,
   страны, замечания, сколько анкоров **станут неактивными** и **снова включатся**.
   В базу ещё ничего не записано. Список отсутствующих показан отдельно.
   Новые безанкорные записи помечены как **Бренд**, **Голый адрес** или
   **Нейтральное слово**. Тип определяется по тексту ссылки.
6. Нажмите **Записать в базу**.

## Вся таблица линкбилдинга и регионы {#regions}

В книге бывают листы анкоров нескольких регионов: «Распределение анкоров EN»
и «Распределение анкоров BR». Система берёт лист с пометкой региона в
названии: «BR» или «Бразилия» — для Бразилии, «EN», «US» или «США» — для США.

- **Цели по типам страниц** и **страны** — общие для продукта: берутся из
  книги при любом регионе.
- **Лист безанкорки без пометки региона** («Распределение безанкорки») —
  это безанкорка основного списка, США. К другому региону он не применяется,
  в сводке это написано. Безанкорку Бразилии загрузите листом с «BR» в
  названии или отдельным файлом с регионом «Бразилия».

## Результат

Итог: сколько анкоров добавлено и обновлено, замеров записано, долей и
сколько старых ссылок получили анкор. **К анкорам** — страница анкоров
продукта с новыми данными.

Листы долей из той же книги разбираются сами, без разметки:

- **Распределение по типам страниц** — цель и деление на прямой /
  разбавленный / безанкор;
- **Распределение безанкорки** — бренд, адрес и нейтральные слова со своими
  процентами; старые ссылки «Convertio», «click here» получают этот анкор и
  начинают считаться в долях;
- **Распределение по странам**.

Файл ключей сравнивается только с ключами продукта; файл безанкорки — только
с безанкорными анкорами. Книга с обоими листами сравнивает оба списка.
Отключённые не участвуют в статистике и выборе для новых размещений, но
сохраняют связь со старыми размещениями и позиции.

Анкор, который вернулся в файл, снова становится активным с тем же ID.
Повтор того же файла тоже может включить анкор, отключённый после прошлой
загрузки; если база уже соответствует файлу, повтор ничего не меняет.
Одна строка, попавшая и в список анкоров, и в лист безанкорки, сохраняется
один раз со своим безанкорным типом и долей.

## Если что-то пошло не так

- **«Укажите колонку с анкором…» / «…куда ведёт»** — на шаге колонок
  выберите их вручную.
- **«У позиции … нет даты в заголовке»** — переименуйте колонку в файле:
  «Pos 22.09.26».
- **«В книге несколько листов анкоров…»** — в названии нужного листа нет
  пометки региона. Переименуйте лист («Распределение анкоров BR») или
  скачайте его отдельным CSV.
- **«Похоже, это анкоры региона «Бразилия»…»** — лист или файл помечен другим
  регионом: «BR» или «Бразилия» в названии при регионе «США», «EN» при
  регионе «Бразилия». Выберите правильный регион или переименуйте лист.
- **Ошибочно загрузили не тот регион** — отмените загрузку в **Загрузках**:
  уйдёт и список, который она завела. Или удалите список на странице
  **Анкоры**: [Списки по регионам](../reference/anchors.md#regions).
- **Замечания** в сводке — строка без адреса, повтор анкора, не число в
  объёме. В режиме дополнения строка с ошибкой пропускается. В режиме полного
  списка файл с замечаниями или без валидных анкоров не записывается: исправьте
  файл или выберите дополнение. Так ошибочный файл не отключит рабочий список.
