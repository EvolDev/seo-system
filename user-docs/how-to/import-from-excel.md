# Как загрузить таблицу в систему

После загрузки площадки из таблицы видны в админке: с метриками, ценами,
вашими решениями и размещениями, а ключи — с позициями. Загружать можно
повторно: пока вы ведёте таблицу, новые площадки, решения и размещения
подтягиваются поверх уже загруженного, ничего не дублируется.

## Перед началом

- В админке, в разделе **Продукты**, заведены Convertio (`convertio.co`)
  и Clideo (`clideo.com`). Без них загрузка остановится и ничего не
  запишет.
- Таблица сохранена в формате `.xlsx` в папку проекта. В ней есть
  вкладки **База линкбилдинга** и **Распределение анкоров**; вкладка
  **Размещения** — по желанию, с ней система только сверяется.
- Вы знаете дату выгрузки — день, когда в таблицу попали метрики и
  цены. Все метрики и цены из файла запишутся на эту дату.

## Шаги

1. Придумайте имя рабочего списка, например «Октябрь 2026». Все
   площадки файла попадут в этот список. Список с таким именем уже есть —
   загрузка его дополнит.
2. Сначала запустите сухой прогон — он всё посчитает и покажет, но
   ничего не запишет:

    ```
    docker compose run --rm app python manage.py import_workbook "Линкбилдинг Convertio.co.xlsx" --date 2026-10-27 --list "Октябрь 2026" --dry-run
    ```

3. Прочитайте сводку в терминале и полный отчёт — путь к нему в
   последней строке (папка `import-reports`). Что значат разделы — ниже.
4. Если всё устраивает, запустите то же без `--dry-run`. Цифры совпадут
   с сухим прогоном.

## Результат

- В админке, в разделе **Списки площадок**, появился список: сколько в
  нём площадок и сколько из них впервые в базе. По числу площадок
  открывается сам список.
- У площадок — метрики и цены на дату выгрузки, статус для Convertio по
  вашим решениям, размещения со ссылками. Статья Clideo из колонки
  «Пример статьи на Clideo» стала размещением Clideo.
- У ключей — объёмы и позиции по датам из колонок `Pos ДД.ММ.ГГ`.

Если что-то не получилось, загрузка не сделает половину работы: она
записывает либо всё, либо ничего.

## Что загрузка меняет, а что нет

Главнее то, что в системе. Загрузка ведёт себя по-разному в зависимости
от того, откуда данные:

| Данные | При повторной загрузке |
|---|---|
| Карточка Collaborator: языки, тематики, тип ссылки, пометка «реклама», сколько ссылок разрешено; объёмы ключей | берутся из таблицы. Пустая ячейка значение в системе не стирает |
| Метрики, цены, позиции | та же дата — замер обновляется, новая дата — добавляется новый, прежний остаётся в истории |
| Ваши решения и размещения: статус площадки, причина отказа, заметки, статус размещения, адрес статьи, анкоры | только дополняются. Пустое заполняется, размещение продвигается вперёд («Запланировано» → «Заявка отправлена» → «Опубликовано»). Решение, принятое в системе, загрузка не отменяет — расхождение покажет отчёт |

Как читаются колонки:

- «Комментарий к площадке» со словом «отбрасываем» (или «отбрасываю») —
  отказ для Convertio, текст становится причиной. Другой комментарий —
  заметка о площадке.
- Анкор без статуса — размещение «Запланировано», площадка
  «Одобрена».
- Колонку «Новая?» вести больше не нужно: площадки, которых раньше не
  было в базе, список помечает сам.

## Если что-то пошло не так

| Что видите | Что это значит | Что делать |
|---|---|---|
| «Нет продукта с доменом …» | продукт не заведён | заведите Convertio и Clideo в разделе **Продукты** и повторите |
| «Во вкладке … нет колонок: …» | колонку переименовали или удалили | верните колонке прежнее название — система ищет колонки по заголовку |
| Раздел отчёта «Отказы площадок в комментариях» | в комментарии написано, что площадка отказала, а статус в таблице этого не говорит | откройте размещение в админке и поставьте статус **Отклонено** |
| Раздел «Решения по площадкам: расхождения с базой» | в системе решение уже другое | если верно то, что в системе, поправьте таблицу; загрузка его не тронет |
| Раздел «Битые ячейки «Пример статьи на Clideo»» | в ячейке не адрес статьи на этой площадке | поправьте ячейку в таблице |
| Раздел «Links Placed / Links Waiting» | счёт по размещениям не сходится с формулой в таблице | проверьте формулу в строке: обычно она ссылается не на тот ключ |
| Раздел «Сверка с вкладкой «Размещения»» | копия на вкладке «Размещения» разошлась с основной | загрузка берёт основную вкладку; поправьте ту, где ошибка |
| Раздел «Анкоры без ключа» | анкор не совпал ни с одним ключом: бренд, адрес, «click here» | это нормально для безанкорных ссылок; если это ключ — проверьте написание |
