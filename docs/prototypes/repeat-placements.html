Что поменялось после замечаний

  • Статус площадки — по её размещениям. Свой статус у неё есть, только пока размещений нет: Новая, Просмотрено, Отбрасываю, Отказ, Чёрный список.
  • Когда размещения есть, на вкладке «Площадка» вместо статусов — список размещений и «Больше не работаем».
  • Фишки — полным названием статуса и датой, когда его поставили.
  • Период — кнопкой рядом со статусами: месяц, 3 месяца, год, всё время или свой — с месяца и года по месяц и год. Работает с любым выбранным статусом — по дате, когда его поставили: «Просмотрено» за месяц, «Новая» за неделю, «Размещено» за сентябрь.
  • Повтор может идти параллельно с идущим размещением.
  • Другие продукты — только для просмотра: статус, ссылка на статью и карточка их размещения видны, но не меняются. Менять — переключив продукт в шапке.
  • Сотрудник в новом размещении подставляется сам — тот, кто вошёл.

Что потыкать

  1. spacecoastdaily.com → домен: панель открывается на размещении, на вкладке «Площадка» статусов больше нет.
  2. Статус «Просмотрено» + «Период ▾» → «Месяц»: только просмотренные за месяц. «Новая» + «Месяц» — добавленные за месяц.
  3. «Размещено» + свой период с сентября по октябрь 2026; «Год» — у globalbizwire.net и trendwatchers.net старые размещения пропадают.
  4. videomakerhub.com → домен → «Взять в размещение» на вкладке «Площадка».
  5. techpulse-daily.com → «+ Ещё размещение» → LinkHouse, он дешевле.
