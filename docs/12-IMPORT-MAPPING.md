# 12. Маппинг импорта

Как колонки Excel превращаются в схему. Все примеры и счётчики взяты из
реальных выгрузок, не выдуманы. Задача — **E1-04**.

Версия 2 от 23.09.2026: переписано после того, как выгрузка базы выросла
и оказалась другим набором данных (см. §0).

---

## 0. Источники — их два, и терять нельзя ни один

| Выгрузка | Дата | Строк | Что внутри |
|---|---|---|---|
| **Рабочая база** | 17.09.2026 | 568 | площадки, по которым шла работа: 38 решений, 10 размещений, 87 комментариев |
| **Пул кандидатов** | 23.09.2026 | 1978 (1494 уникальных) | свежая выгрузка каталога Collaborator, отсортирована по DR; ни одного статуса, комментария и размещения |

Обе выгрузки называются «База линкбилдинга» и имеют одинаковые 33
колонки, но **не пересекаются**: ни одной площадки из 38 отработанных в
пуле нет. Если импортировать только текущую вкладку, пропадёт вся
история решений и размещений.

Порядок импорта:
1. Рабочая база — источник решений, размещений и ссылок.
2. Пул — источник новых кандидатов. Площадки, уже существующие после
   шага 1, пулом **не перезаписываются**: обновляются только метрики и
   цены новым снапшотом.

Где сейчас лежит рабочая база и будет ли она ещё пополняться — открытый
вопрос Q11.

---

## 1. Лист «База линкбилдинга»

### 1.1. Предобработка — до разбора колонок

**Дубли строк.** В пуле 23.09 каждый из 484 доменов встречается ровно
дважды: у 466 пар строки идентичны целиком, у 18 отличается только
`Organic / Total Keywords`. Похоже, часть данных вставили в таблицу
дважды.

Правило:
- полностью идентичные строки — сливаются молча, в отчёте счётчик;
- строки одного домена с разными значениями — берётся первая, конфликт
  выводится в отчёт с обоими значениями.

**Категории с запятой внутри.** В колонках «Тематика» и «Особые
тематики» несколько категорий перечислены через запятую, но у части
категорий запятая есть в самом названии: «Кредитование, микрозаймы»,
«Форекс, брокеры», «Общество, политика, законы», «Шопинг (сайты для
покупок, купоны)». Простое деление по запятой превращает четыре особые
тематики в шесть обрывков.

Правило разбора: новая категория начинается после запятой, только если
следующий фрагмент начинается с заглавной буквы и запятая не внутри
скобок. На выгрузке 23.09 это даёт ровно 44 категории тематик и 4 особые
тематики, без единого обрывка. Результат сверяется со словарём
(`domain_settings`); незнакомая категория — в отчёт.

**Итог цена = 0 при заполненной цене размещения** — 82 площадки в пуле.
Промпт аудитора прямо предупреждает, что этому полю доверять нельзя.
Колонка не импортируется (§4), но число таких строк идёт в отчёт.

### 1.2. В таблицу `sites`

| Колонка Excel | Поле | Преобразование |
|---|---|---|
| Target | `domain` | нижний регистр, снять схему, `www.`, хвостовой слэш |
| Источник | `source` | всегда `Collaborator` в обеих выгрузках |
| Языки сайта | `languages`, `language` | разбить по запятой в `languages`; первый элемент → `language` в ISO: «Английский» → `en`, «Украинский» → `uk`. Пул: «Английский» 834, «Украинский, Русский» 68, «Немецкий» 64 |
| Тип сайта | `site_type` | как есть. Пул: персональный блог 1212, информационный сайт 182, СМИ 70, портал 24, корпоративный блог 5, интернет-магазин 1 |
| Тематика | `topics` | разобрать по правилу из §1.1: «Бизнес и финансы, СМИ (Новости), Общество, политика, законы» → три категории. Всего 44 |
| Особые тематики | `declared_topics` | то же правило; категорий ровно четыре. **Это не проверка индекса**, см. §1.6 |
| URL Коллаборатора | `collaborator_url` | как есть |
| Количество ссылок статья | `links_allowed` | целое. Пул: 1 — 618, 2 — 673, 3 — 203 |
| Комментарий к площадке | `reject_reason` / `notes` + `status` | см. §1.6 |
| Тип ссылки статья | `link_type` | `dofollow` / `nofollow` как есть. Основа `STOP_NOFOLLOW` и предфильтра. В пуле все 1494 — `dofollow` |
| Пометка о рекламе статья | `marks_as_ad` | `Да` → `true`, `Нет` → `false`. Основа `STOP_AD_LABEL`, см. §1.6 |

Цена написания в `sites` **не попадает**: признак «пишем ли мы» считает
`v_site_latest` из последних цен. Отдельная колонка разъехалась бы с
ценами после первого же обновления.

### 1.3. В таблицу `site_metrics` — один снапшот на строку

| Колонка Excel | Поле | Преобразование |
|---|---|---|
| DR | `dr` | число; в пуле одна строка без DR → `NULL` |
| Organic / Traffic | `organic_traffic` | **строка с запятыми**: `84,307,672` → int. В пуле с запятыми 1020 значений из 1439 |
| Top Geo | `top_geo` | код страны. Пул: `us` 530, `in` 135, `ua` 112, `de` 77, `gb` 56 |
| Top Geo Traff | `top_geo_traffic` | те же запятые |
| US Traff | `us_traffic` | те же запятые |
| Organic / Total Keywords | `total_keywords` | те же запятые |

`source = csv_import`, `checked_at` = дата выгрузки файла, **не** `now()`
— иначе история соврёт.

Контрольная проверка: `US Traff` совпадает с `Top Geo Traff` у 544 строк
пула — у 529 из них Top Geo действительно `us`, у 15 нет. Эти 15 — в
отчёт; в рабочей базе таких было 3. Ещё у одной `us`-площадки трафики не
совпадают. Систематического дублирования колонок нет.

### 1.4. В таблицу `site_prices` — один снапшот на строку

| Колонка Excel | Поле | Преобразование |
|---|---|---|
| Цена размещения статья, EUR | `placement_cents` | float → центы с округлением: `18.2` → `1820` |
| Цена анонса статья, EUR | `announce_cents` | **смешанный тип**: число → центы; `бесплатно` → `0`; пусто → `NULL`. Пул: 487 непустых, из них 337 «бесплатно» |
| Цена написания статья, EUR | `writing_cents` | float → центы; пусто → `NULL` (площадка не пишет) |

Валюта везде `EUR`.

### 1.5. В таблицы `placements` и `placement_links`

Только из рабочей базы — в пуле размещений нет.

Размещение создаётся для строк, где есть статус, дата размещения или URL
статьи. Продукт — Convertio.

| Колонка Excel | Поле | Преобразование |
|---|---|---|
| Статус | `placements.status` | «Размещено» → `published`; «Заявка отправлена» → `ordered` |
| URL статьи | `placements.article_url` | как есть |
| Дата размещения | `placements.published_at` | формат `DD.MM.YYYY`: `14.09.2026` |
| Месяц | — | не импортируем, производное от даты (`Sep-26`) |
| Индексация | `placements.is_indexed` | **регистр разъезжается**: `да`, `Да`, `Нет` → bool; пусто → `NULL` |
| Комментарий по размещению | `placements.comment` | как есть |
| Тип ссылки | `placements.placement_type` | `Guest Post` → `guest_post`, `Link Insertion` → `link_insertion`. Это формат размещения, **не** dofollow/nofollow |
| Анкор1 / Ссылка1 | `placement_links`, `link_index = 1` | |
| Анкор2 / Ссылка2 | `placement_links`, `link_index = 2` | |

`placement_links.rel` импорт **не заполняет**: это атрибут со страницы,
его запишет краулер (E2-04). Заявленный тип ссылки площадки лежит в
`sites.link_type`.

**Статус площадки по размещениям.** Площадка с опубликованным размещением
Convertio → `placed`; с заявкой → `approved`. Размещения Clideo статус не
меняют: `placed` означает «размещались под основной продукт».

Две колонки с похожими названиями — «Тип ссылки» и «Тип ссылки статья» —
означают разное. Перепутать легко, а вторая участвует в стоп-факторе.

Привязка ссылки к `keywords` — по точному совпадению текста анкора с
`keyword`. Не нашлось — `keyword_id = NULL` и строка в отчёт: это либо
безанкорка вроде `convertio.co`, либо ключ не заведён.

Реальные связки из рабочей базы:
- `mp4 to mp3` → `https://convertio.co/mp4-mp3/`
- `online video converter` → `https://convertio.co/video-converter/`
- `convert` → `https://convertio.co/`
- `convertio.co` → `https://convertio.co` (брендовая)

### 1.6. Особые случаи

**Пример статьи на Clideo.** Это **размещение продукта Clideo**, а не
колонка площадки (ADR-007). Для каждой непустой ячейки — `placement` с
`product = Clideo`, `status = published`, `article_url` = значение.
Строк в `placement_links` импорт не создаёт — анкор неизвестен. Первый
же обход (E2-05) ищет на странице любую ссылку на `clideo.com`: нашлась —
создаётся строка ссылки; страница отдаёт 200, а ссылки нет при двух
проверках — это и есть сигнал `CLIDEO_LINK_REMOVED`; страница 404 или
недоступна — вопрос человеку, не вывод. В пуле таких площадок 120.

**Пометка о рекламе статья = `Да`.** `sites.marks_as_ad = true`,
сработал `STOP_AD_LABEL`: `site_audits` с вердиктом `no`, блокером и
`author = system`, площадка → `rejected`. Рабочая база: 62 из 568.
Пул: 109 из 1494.

**Особые тематики.** Декларация площадки на Collaborator о том, какие
тематики она **принимает**. Не результат gray scan. Пул: заполнено у 601
из 1494; чаще всего «Азартные игры, Кредитование, микрозаймы, Форекс,
брокеры, Сайты знакомств» (284). Хранится в `declared_topics`, в оценке —
отдельный фактор гибкой зоны (`04-DOMAIN-RULES.md` §1.2).

**Комментарий к площадке** (только рабочая база, 87 строк). Содержит и
причину отказа, и заметки. Если строка содержит «отбрасываем» — статус
`rejected`, текст в `reject_reason`. Иначе — в `notes`, статус `new`.
Топ причин: «Nofollow, отбрасываем» (11), «Не тематика, отбрасываем» (7),
«Серая тематика в поиске, отбрасываем» (6).

**Строки без решения.** Всё, что не получило статус выше, → `status = new`,
`imported_undecided = true`. Так их можно отличить от действительно новых
доменов, добавленных после импорта.

### 2.1. В таблицу `keywords`

| Колонка | Поле | Преобразование |
|---|---|---|
| Keyword | `keyword` | как есть, дублей нет |
| URL | `target_url` | как есть |
| Volume | `volume` | строка с запятыми: `42,000` → int. **Две битые ячейки**, см. ниже |
| Global Volume | `global_volume` | то же |
| Tool | `tool` | Image 51, Video 27, Audio 20, Main 9, Doc 6 |
| Type | `page_type` | тип **страницы**, не анкора: «Главная» 9, «Основные разделы» 14, «Video (xxx-yyy)» 20, «Audio (xxx-yyy)» 13, «Одиночные форматы (xxx)» 11, «Остальное» 46. В `anchor_type` не класть — там перечисление типов анкора, импорт упадёт |

**Битые данные на 23.09.2026:**
- `convert heic to jpg` — в Volume вставлен текст `The article I have in
  mind: https://blog.designcrowd.com`, похоже, из буфера обмена;
- `heic to jpg` — Volume пустой.

Правило: нечисловое значение → `NULL` и строка в отчёт, импорт не падает.
Сами ячейки стоит поправить в таблице.

**Links Placed / Links Waiting не импортируем** — они вычисляются из
`placement_links` (E1-05). Для контроля: на 23.09 заполнены у 21 и 37
ключей, в сумме 38 и 57 ссылок. После импорта рабочей базы расчётные
значения сверяются с этими колонками; расхождение — в отчёт. Оно почти
наверняка будет, пока рабочая база не восстановлена полностью (Q11).

### 2.2. В таблицу `keyword_positions`

**Каждая колонка вида `Pos DD.MM.YY`** → снапшот на эту дату, страна
`US`, `source = csv_import`. Колонок столько, сколько есть в файле: на
17.09 их было три, на 23.09 — четыре (добавилась `Pos 22.09.26`). Скрипт
находит их по шаблону имени, а не по списку.

**`101` — это не позиция, а метка «вне топ-100».** Импортировать как
`NULL`. Встречается 1–2 раза на дату: `photo converter` на 22.09 (при
позиции 19 неделей раньше), `video converter` на 02.09.

Контроль после импорта: ключ `convert` — 7, 5, 14, 7 по датам
02.09 → 22.09. Если на графике это видно, снапшоты легли правильно.

## 3. Требования к скрипту импорта

1. **Два источника, один проход.** Рабочая база, затем пул (§0).
2. **Идемпотентность.** Повторный запуск не создаёт дублей. Ключи:
   `sites.domain`; для позиций — `(keyword, country, дата)`; для
   снапшотов метрик и цен — `(site, дата выгрузки)`.
3. **Отчёт обязателен:** создано / обновлено / пропущено; слитые дубли и
   конфликты; нечисловые значения; строки с «Итог цена = 0»; анкоры без
   ключа; расхождения `links_placed` с файлом; строки с `US Traff` =
   `Top Geo Traff` при не-US гео.
4. **Сухой прогон** — `--dry-run`: всё то же, без записи.
5. **Ни одна строка не теряется молча.** Не разобралась — в отчёт.
6. **Транзакция.** Импорт целиком применяется или откатывается.

## 5. Листы, которые пока не используем

«Распределение безанкорки», «Распределение по типам страниц»,
«Распределение по странам» — целевые доли портфеля. По промпту аудитора
это фоновый контекст, не правило выбора анкора. Импортировать структуру
можно, применять — нет, до отдельного решения (Q10).
