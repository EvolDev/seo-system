# 12. Маппинг импорта

Как колонки таблицы ручной работы превращаются в схему. Все примеры и
счётчики — из реального файла, не выдуманы. Задача — **E1-04**.

Версия 3 от 27.09.2026: переписано под файл от 27.09 (Q11 закрыт), под
регулярный импорт и рабочие списки (ADR-033) и под пометку «реклама»,
которая не стоп-фактор (ADR-034). Версия 2 описывала две выгрузки —
рабочую базу 17.09 и пул 23.09; в файле от 27.09 они сведены в одну
вкладку.

## 0. Источник, запуск, правила повторного импорта

**Файл** — `Линкбилдинг Convertio.co.xlsx`, таблица, в которой идёт
ручная работа. Лежит в корне проекта, в git не идёт (`*.xlsx`):
внутри цены и контакты.

| Вкладка | Строк | Что делаем |
|---|---|---|
| База линкбилдинга | 1978 | основной источник: площадки, замеры, решения, размещения Convertio и Clideo (§1) |
| Распределение анкоров | 113 ключей | ключи и позиции (§2) |
| Размещения | 51 | не импортируем — ручная копия размещённых строк основной вкладки; только сверка (§1.8) |
| Other Databases | 32, без заголовка | не импортируем — старый срез тех же площадок, в основной вкладке по ним всё новее |
| База Starmedia | 679 | не импортируем — каталог другого продавца, свой формат, цены в $ |
| Дополнительные площадки | 277 | не импортируем — контакты линкбилдеров, не площадки |
| Распределение безанкорки, по типам страниц, по странам | — | не используем (§5) |

**Запуск:**

```
python manage.py import_workbook "<файл>" --date 2026-09-27 --list "Сентябрь 2026" [--dry-run]
```

`--date` — дата выгрузки: в файле её нет, а от неё зависят снапшоты.
`--list` — рабочий список, в который попадут площадки файла (§1.7).

**Продукты.** Convertio (`convertio.co`) и Clideo (`clideo.com`) заводит
человек в админке **до** импорта. Скрипт находит их по домену; продукта
нет — импорт останавливается с понятной ошибкой, ничего не записав.

**Колонки ищутся по заголовку**, не по позиции. Нет обязательной
колонки — импорт останавливается и называет её. Лишние колонки не
мешают.

**Повторный импорт (ADR-033).** Таблицу ведут до подключения API, импорт
регулярный, главнее админка. По видам данных:

| Вид | Что входит | При повторном импорте |
|---|---|---|
| Факты из внешних источников | карточка Collaborator (§1.2), объёмы ключей | перезаписываются непустыми значениями из таблицы, изменения — в отчёт. Пустая ячейка значение в базе не стирает: битая ячейка не должна затирать хорошие данные |
| Замеры | метрики, позиции | снапшот на `--date`; та же дата — обновляется, новая — новая строка |
| Цены (ADR-043) | предложения Collaborator | снапшот на `--date`. Первая цена площадки становится рабочей. Рабочую цену импорт не меняет: другая цена — новое предложение, ждёт решения человека (§1.4) |
| Заметки (ADR-043) | «Комментарий к площадке» | в историю заметок; новый текст — новая заметка, тот же — пропуск (§1.6) |
| Решения и работа | статус по продукту, причина отказа, размещения, ссылки, раздел и тип страницы ключа, его адрес | только дополняются: недостающее создаётся, пустое заполняется, статусы двигаются вперёд. Заполненное и принятое не трогается, расхождение — в отчёт |

**Решения — под Convertio (ADR-030).** Факты о площадке общие для всех
продуктов. Решения из таблицы — статус, причина отказа — принимались для
Convertio и ложатся в строку Convertio в `product_sites`. Строка Clideo
меняется только от примеров статей Clideo (§1.6). Строки других
продуктов остаются `new`.

## 1. Вкладка «База линкбилдинга»

### 1.1. Предобработка — до разбора колонок

**Пустые строки** пропускаются, их число — в заметках отчёта. Строка
без `Target`, но с данными не импортируется и идёт в отчёт.

**Домен** нормализуется одной функцией на всю систему
(`apps/sites/domains.py`). Не разобрался — строка в отчёт и не
импортируется. В файле от 27.09 все 1978 доменов уже нормализованы и
уникальны.

**Дубли строк.** В файле от 27.09 их нет, но в выгрузке 23.09 каждый из
484 доменов встречался дважды. Правило остаётся:
- полностью одинаковые строки сливаются молча, в отчёте — счётчик;
- строки одного домена с разными значениями — берётся первая, конфликт
  идёт в отчёт с обоими значениями.

**Числа.** В xlsx числа приходят числами. Строки тоже разбираются:
`84,307,672` (запятые — вид CSV-выгрузки), `24 195 783`. Не число —
`NULL` и строка в отчёт, импорт не падает.

**Категории с запятой внутри.** В «Тематике» и «Особых тематиках»
категории перечислены через запятую, но запятая бывает и в названии:
«Кредитование, микрозаймы», «Форекс, брокеры», «Общество, политика,
законы», «Шопинг (сайты для покупок, купоны)». Правило: новая категория
начинается после запятой, только если следующий фрагмент начинается с
заглавной буквы и запятая не внутри скобок. На файле от 27.09 это даёт
ровно 44 тематики и 4 особые тематики без единого обрывка.

Словаря категорий пока нет (`domain_settings` появятся в E1-05), поэтому
отчёт показывает категории, которых ещё не было в базе. На первом
импорте это весь список.

**Итог цена = 0 при заполненной цене размещения** — 523 строки. Промпт
аудитора прямо предупреждает, что этому полю доверять нельзя. Колонка
не импортируется (§4), число строк идёт в отчёт.

### 1.2а. В таблицу `product_sites` — решение под Convertio

Строки под все продукты создаёт та же функция, что и для любой новой
площадки (`ensure_product_sites`). Импорт меняет строку Convertio по
решению из строки таблицы, по старшинству:

1. есть опубликованное размещение Convertio (§1.5) → `placed`;
2. есть заявка или запланированное размещение → `approved`
   («Одобрена» — сюда же попадают площадки с заявкой);
3. комментарий с отказом (§1.6) → `rejected`, текст → `reject_reason`;
4. иначе решения нет.

Статус меняется, только если сейчас `new`, или вперёд по цепочке
`new` → `approved` → `placed` (ADR-033). Отклонённую, чёрный список, на
аудите импорт не трогает; расхождение с таблицей — в отчёт.

`imported_undecided = true` — площадка создана этим импортом, а решения
по Convertio в таблице нет. Флаг снимается, когда решение появляется. У
строк других продуктов он `false`: решений под них в таблице не было.

На файле от 27.09 для Convertio: `placed` 52, `approved` 52 (27 заявок и
25 запланированных), `rejected` 62, `new` 1812 — все с
`imported_undecided`.

### 1.3. В таблицу `site_metrics` — снапшот

| Колонка Excel | Поле | Преобразование |
|---|---|---|
| DR | `dr` | число; пусто → `NULL` (1 строка: punslogo.com) |
| Organic / Traffic | `organic_traffic` | число (§1.1) |
| Top Geo | `top_geo` | код страны как есть: `us` 781, `in` 186, `ua` 122; всего 88 стран |
| Top Geo Traff | `top_geo_traffic` | число |
| US Traff | `site_country_metrics`, страна `us` — `organic_traffic` | число; см. ниже про строки без данных. Отдельный снимок с тем же источником и датой (ADR-045): это трафик США у каждой площадки, не топ-регион |
| Organic / Total Keywords | `total_keywords` | число |

`source = csv_import`, `checked_at` = `--date` (начало дня по времени
проекта), **не** `now()` — иначе история соврёт. Ключ снапшота —
площадка, `csv_import`, дата: есть — обновляется, нет — вставляется.

**Строки без данных Ahrefs.** У 37 строк пусты трафик, ключи, Top Geo и
его трафик, а US Traff = 0. Это «нет данных», а не ноль трафика: такой
`0` пишется как `NULL`, число строк — в отчёт. Ещё у 18 строк пуст
только общий трафик — пишется как есть.

Контрольная проверка: US Traff совпадает с Top Geo Traff при Top Geo не
`us` и ненулевом трафике — в отчёт. В выгрузке 23.09 таких было 15. В
файле от 27.09 совпадений при не-US гео тоже 15, но все — `0 = 0` у
площадок без трафика; настоящих — ни одного. Систематического
дублирования колонок нет.

### 1.4. В таблицу `site_prices` — снапшот

| Колонка Excel | Поле | Преобразование |
|---|---|---|
| Цена размещения статья, EUR | `placement_cents` | евро → центы с округлением: `18.2` → `1820` |
| Цена анонса статья, EUR | `announce_cents` | **смешанный тип**: число → центы (202); `бесплатно` → `0` (437); пусто → `NULL` |
| Цена написания статья, EUR | `writing_cents` | число → центы (1438); пусто → `NULL` — площадка не пишет |

Валюта везде `EUR`, `source = csv_import`, дата и ключ — как у метрик.
Продавец — Collaborator, услуга — публикация (`guest_post`), ADR-043.

Рабочая цена (`sites.price_id`):
- у площадки её нет — новое предложение становится рабочим и сразу
  разобранным (`reviewed_at` заполнено);
- есть — новое предложение ждёт решения (`reviewed_at` пусто), если
  отличается от текущей цены Collaborator; та же цена на новую дату
  решения не требует;
- снимок той же даты обновляется на месте, кроме рабочего: рабочую
  цену импорт не переписывает — другая цена той же даты встаёт рядом
  новой строкой.

### 1.5. В таблицы `placements` и `placement_links` — размещения Convertio

Размещение создаётся для строки, где заполнено хоть что-то из: статус,
URL статьи, дата размещения, анкор. Продукт — Convertio.

| Колонка Excel | Поле | Преобразование |
|---|---|---|
| Статус | `placements.status` | «Размещено» → `published` (52); «Заявка отправлена» → `ordered` (27); пусто, но есть анкор, URL или дата → `planned` (25). Другое значение — строка в отчёт, размещение не создаётся |
| URL статьи | `placements.article_url` | как есть |
| Дата размещения | `placements.published_at` | `DD.MM.YYYY` → начало дня по времени проекта |
| Месяц | — | не импортируем, производное от даты |
| Индексация | `placements.is_indexed` | **регистр разъезжается**: `да`, `Да`, `Нет` → bool; пусто → `NULL` |
| Комментарий по размещению | `placements.comment` | как есть |
| Тип ссылки | `placements.placement_type` | `Guest Post` → `guest_post` (48), `Link Insertion` → `link_insertion` (2). Это формат размещения, **не** dofollow/nofollow |
| Анкор1 / Ссылка1 | `placement_links`, `link_index = 1` | анкор и адрес как есть |
| Анкор2 / Ссылка2 | `placement_links`, `link_index = 2` | |

Всего на файле от 27.09: 104 размещения, 136 ссылок.

Не заполняются: `rel` — атрибут со страницы, его запишет краулер
(E2-04); `ordered_at` — даты заявки в таблице нет; `price_paid_cents` —
в таблице цена каталога, а не уплаченная.

Две колонки с похожими названиями — «Тип ссылки» и «Тип ссылки статья»
— означают разное. Перепутать легко, а вторая участвует в стоп-факторе.

**Привязка ссылки к ключу** — точное совпадение текста анкора с
`keywords.keyword` продукта. Совпали 114 из 136. Остальные 22 — бренд
(«Convertio», «Convertio — File Converter», «Go to Convertio»), адрес
(«convertio.co») или общие слова («click here», «Read more»):
`keyword_id = NULL`, строки в отчёт. Адрес ссылки не совпадает с адресом
ключа — в отчёт: `mkv to mp4` ведёт на `https://convertio.co/`, а у
ключа `/mkv-mp4/`.

**Какое размещение обновлять при повторном импорте.** Естественного
ключа у размещения нет. Среди размещений Convertio на этой площадке:
с тем же `article_url` — оно; иначе единственное без `article_url` —
оно; нет ни одного — создаётся новое; неоднозначно — строка в отчёт,
ничего не трогается. Статус — только вперёд по цепочке `planned` →
`ordered` → `published`; `rejected` и `cancelled` импорт не трогает.
Ссылки — по `link_index`: нет — создаётся, анкор или адрес другой — в
отчёт.

**Отказы площадок.** В колонке «Статус» нет значения «отказали». Если в
комментарии строки с размещением есть «отказ» или «отклон», строка
идёт в отчёт, статус из текста не выводится — его ставит человек в
админке. На файле от 27.09 таких пять: contiki.com, freewebsubmission.com,
timesca.com, onrec.com, theyogacollective.com.

### 1.6. Особые случаи

**Пример статьи на Clideo.** Это **размещение продукта Clideo**, а не
колонка площадки (ADR-007). Для каждой непустой ячейки — `placement` с
`product = Clideo`, `status = published`, `article_url` = значение, а
строка площадки для Clideo в `product_sites` → `placed` (по правилу
§1.2а). Строк в `placement_links` импорт не создаёт — анкор неизвестен.
Первый же обход (E2-05) ищет на странице любую ссылку на `clideo.com`:
нашлась — создаётся строка ссылки; страница отдаёт 200, а ссылки нет
при двух проверках — это и есть сигнал `CLIDEO_LINK_REMOVED`; страница
404 или недоступна — вопрос человеку, не вывод.

Ячейка должна быть адресом `http(s)://` на домене площадки или его
поддомене; иначе размещение не создаётся, строка — в отчёт. На файле от
27.09: 603 ячейки, 599 годных и 4 в отчёт — bookafy.com и urbanmatter.com
(ссылка на чужой домен), debutify.com (`(Convertio) https://…` — похоже
на старое размещение Convertio), biernet.nl (без `https://`). Размещение
Clideo ищется по площадке и `article_url`.

**Пометка о рекламе статья = `Да`** (164 строки). Только
`sites.marks_as_ad = true`. Площадка объявляет пометку заранее, она
оговорена — это не стоп-фактор (ADR-034). Ни аудита, ни смены статуса
импорт не делает. На трёх таких площадках уже вышли статьи, на одну
отправлена заявка.

**Особые тематики.** Декларация площадки на Collaborator о том, какие
тематики она **принимает**. Не результат gray scan. Заполнено у 788
строк: «Форекс, брокеры» 677, «Кредитование, микрозаймы» 659, «Азартные
игры» 613, «Сайты знакомств» 406. Хранится в `declared_topics`, в
оценке — отдельный фактор гибкой зоны (`04-DOMAIN-RULES.md` §1.2).

**Комментарий к площадке** (202 строки) содержит и причину отказа, и
заметки. Если в нём есть «отбрасыва» — «отбрасываем» или «отбрасываю»,
— это отказ для Convertio: `status = rejected`, текст →
`reject_reason` (62) и заметка в `site_notes` с продуктом Convertio.
Иначе — заметка о площадке в `site_notes` без продукта (140). Источник
заметок — «таблица линкбилдинга» (ADR-043). Топ причин: «Nofollow,
отбрасываем» (11), «Не тематика, отбрасываем» (7), «Серая тематика в
поиске, отбрасываем» (6). При повторном импорте причина в решении только
заполняется (другой текст — в отчёт), а заметка: новый текст — новая
заметка в истории, тот же — пропуск.

### 1.7. Рабочий список

Все площадки вкладки попадают в список `--list` (`site_list_items`,
ADR-033). Списка с таким именем нет — создаётся, есть — дополняется;
площадка уже в списке — пропускается. `first_seen = true` — площадку
создал этот импорт.

Файл от 27.09 — список «Сентябрь 2026», 1978 площадок; `first_seen` у
всех, база была пустой.

Колонка «Новая?» не импортируется: это ручная отметка второй подгрузки
в ту же вкладку, её работу теперь делает `first_seen`.

### 1.8. Сверка с вкладкой «Размещения»

Вкладка — ручная копия размещённых строк основной вкладки, с тем же
набором колонок. Импорт её не записывает, а сверяет по домену: статус,

отчёт. На файле от 27.09:
- therooftopguide.com — в копии «404 Ошибка», в основной «Размещено»;
- citybiz.co — дата 14.09 в копии, 16.09 в основной;
- тип ссылки заполнен только в копии — 10 строк;
- intheplayroom.co.uk размещена в основной, в копии её нет.

## 3. Требования к скрипту импорта

1. **Один файл, один проход.** Сначала ключи (к ним привязываются
   анкоры), затем основная вкладка, затем сверки.
2. **Идемпотентность.** Повторный запуск не создаёт дублей. Ключи:
   `sites.domain`; `product_sites` — `(site, product)`; снапшоты метрик
   и цен — `(site, csv_import, дата)`; позиции —
   `(keyword, country, дата)`; ключи — `(product, keyword)`; размещения
   — §1.5 и §1.6; ссылки — `(placement, link_index)`; список —
   `(list, site)`.
3. **Отчёт обязателен:** создано / обновлено / пропущено по каждой
   таблице; перезаписанные факты каталога; решения и поля, которые
   импорт не тронул из-за расхождения с базой; слитые дубли и
   конфликты; нечисловые значения; строки без данных Ahrefs; строки с
   «Итог цена = 0»; US Traff = Top Geo Traff при не-US гео и ненулевом
   трафике; незнакомые
   языки и новые категории; анкоры без ключа и с чужим адресом;
   неизвестные статусы и отказы в комментариях; битые ячейки Clideo;
   расхождения Links Placed / Waiting; сверка с «Размещениями». Краткая
   сводка — в терминал, полный отчёт — файлом в `import-reports/`.
4. **Сухой прогон** — `--dry-run`: всё то же, включая отчёт, без записи.
5. **Ни одна строка не теряется молча.** Не разобралась — в отчёт.
6. **Транзакция.** Импорт целиком применяется или откатывается.
7. **`run_id`.** Импорт — точка входа цепочки: `new_run_id()` и
   `bind_run_id` (ADR-025); запуск пишется в `task_runs` со сводкой
   отчёта.

## 6. Прайсы продавцов и каталог Collaborator — экран «Загрузки»

Загрузка через админку, не командой (ADR-041, ADR-044); код —
`apps/sites/uploads/`. Порядок: файл → разметка колонок → проверка в
фоне (сводка до записи, база не меняется) → запись в фоне одной
транзакцией → разбор. Сводку и запись строит одна функция плана
(`plan.py`): запись строит его заново по свежему состоянию базы.

### 6.1. Чтение файла

- xlsx (первый непустой лист) и csv: UTF-8 с BOM и без, Windows-1251,
  UTF-16 с меткой порядка байт (выгрузки Ahrefs); разделитель `,`, `;`
  или табуляция — определяется сам.
- Строка заголовков — среди первых 20 строк: первая, где есть колонка
  площадки по словарю синонимов, иначе первая хотя бы с двумя
  заполненными ячейками. Строка с одной ячейкой («sites» в `2.xlsx`) —
  заголовок листа. Человек может указать строку сам.
- Колонка без заголовка, но со значениями — «Колонка E»; без заголовка
  и без значений — её нет. Повтор заголовка — «Price (2)».
- Полностью пустые строки пропускаются, их число — в сводке.

### 6.2. Разметка прайса

Поля: площадка; цена публикации; цена вставки ссылки; цена услуги из
колонки «Услуга» вместе с колонкой «Услуга»; серая цена; написание;
анонс; DR; органический трафик; ключей в органике; тип ссылки; наша
заметка; прочие данные; не загружать. Обязательны площадка и хотя бы
одна цена; поля, кроме прочих данных и «не загружать», — по одной
колонке.

- Догадка — по словарю синонимов (`columns.py`) с уверенностью «точно»,
  «похоже — проверьте», «не знаю → прочие данные». Цена без услуги —
  публикация, а если в файле есть колонка услуги — её цена. Пометка
  коллеги о цене Collaborator («Цена на коллобораторе EUR») — прочие
  данные. Написание и анонс — только «похоже»: бывают в другой валюте.
- Разметка подтверждённого файла пишется в `sellers.column_map`
  (заголовок без регистра → поле). Следующий файл продавца: все непустые
  колонки знакомы — шага разметки нет; новые — вопрос только про них.
- Валюта файла — одна: из заголовка цены («Цена, $»), из знаков в
  значениях («$170.00»), иначе валюта продавца. Для валюты нужен курс
  ЕЦБ, иначе с рабочими ценами не сравнить — разметка не принимается.

### 6.3. Значения

| Что | Как разбирается |
|---|---|
| Площадка | домен по `normalize_domain`; адрес с путём или параметрами — домен и пометка «адрес вместо домена» в сводке. E-mail, пробелы, слово без точки — ошибка строки |
| Цены | `$1 200`, `$170.00`, `311,81`, `1,200.50`, `1.200,50`, `€90`, `90 EUR` → центы. Запятая с группами по три цифры — разряды. Прочерк, `n/a` — пусто. У написания и анонса `free`, `бесплатно` — 0 |
| Числа | `21 400`, `1 072` с неразрывным пробелом, `31.9K`, `1.2M`, `84,307,672`, `35.0` → целое |
| Тип ссылки | `Do-Follow`, `Do Follow`, `Dofollow` → `dofollow`; `No-Follow` → `nofollow` |
| Услуга | «Guest post», «GP», «публикация» → публикация; «Link insertion», «LI», «niche edit», «вставка» → вставка; **«Both» → публикация**, значение «Both» — в прочие данные (Q21) |

Строка без цены, с битой ценой или без услуги при цене из колонки услуги
— ошибка: в сводку с номером строки, не загружается.

**Дубли домена в файле**: цена каждой услуги — меньшая из строк,
остальное — из первой строки, все строки — в сводку.

### 6.4. Каталог Collaborator

Встроенная разметка английской выгрузки (`catalog.py`); нет обязательной
колонки — загрузка не начинается и называет колонки.

| Колонка | Куда |
|---|---|
| Domain | домен (`https://www.tuttotek.it` → `tuttotek.it`) |
| Collaborator URL | `sites.collaborator_url` |
| Category | `sites.topics` — по-русски, словарь 44 тематик; «Society, Politics, and Laws» — одна тематика |
| Special categories | `sites.declared_topics` — по-русски, 4 категории |
| Website languages | `sites.languages` по-русски, первый → `sites.language` (ISO) |
| Website type | `sites.site_type` по-русски; «Publisher» (17 строк на 01.10.2026) словаря не имеет — как есть |
| Link type article, Advertising mark article, Number of links article | `link_type`, `marks_as_ad` (Yes/No), `links_allowed` |
| Publishing price article, EUR | предложение Collaborator, публикация |
| Writing price article, EUR; Announcement price article, EUR; Sensitive topics price, EUR | написание, анонс (`free` — 0), серая цена |
| DR, Organic traffic, Keywords | снимок `site_metrics` с продавцом Collaborator (доверенный) |
| Остальные непустые | `site_prices.extra` предложения Collaborator: TF, CF, Da Moz, Monthly Traffic, Country… |

Факты карточки перезаписываются непустыми значениями, как у таблицы
(ADR-033); что перезаписано — в итоге загрузки. На 01.10.2026 у 1891
площадки из таблицы сменилась ссылка на карточку: в таблице она была из
русского интерфейса (`/ru/creator/…`).

### 6.5. Запись

- **Площадки**: одна на домен; новой — строки «продукт × площадка» со
  статусом «Новая», `imported_undecided` не ставится. `source` — «Collaborator»
  или имя продавца. Тип ссылки из прайса — только если у площадки пусто.
  Площадка, помеченная удалённой, для загрузки новая: запись снимает
  пометку и обновляет описание. Заблокированная (чёрный список у всех
  активных продуктов) — пропускается целиком, в сводке — счётчик.
- **Предложения**: снимок на `prices_date`, `source = csv_import`.
  Снимок той же даты обновляется на месте, если он не рабочая цена;
  рабочая того же дня — остаётся, другая цена встаёт рядом. `reviewed_at`
  пусто только у того, что ждёт решения.
- **Рабочая цена и вкладки** — правило ADR-044 (`plan.classify`):

| Положение | Вкладка | Решение | Рабочая |
|---|---|---|---|
| площадки нет или нет рабочей цены | «Новые» («Отклоняли», если отклоняли) | не нужно | становится сама: публикация, если есть, иначе вставка |
| тот же продавец, та же услуга, та же цена | «Без изменений» | не нужно | переходит на свежий снимок |
| тот же продавец, та же услуга, другая цена | «Цена изменилась» | не нужно; при заявке в работе — нужно | переходит сама; при заявке в работе — нет |
| другая услуга | «Другая услуга» | нужно | — |
| другой продавец, дешевле / дороже / так же в евро | «Дешевле рабочей» / «Дороже рабочей» / «Без изменений» | нужно (кроме «так же») | — |

  Решения не нужно и у предложения, которое продавец уже присылал, его
  разобрали и цена изменилась не больше `OFFER_RECHECK`. Ждущее решения
  на отклонённой площадке (любой активный продукт) — во вкладку
  «Отклоняли». Заявка в работе — размещение любого продукта в статусе
  «заявка отправлена», «пишется», «на проверке».
- **Старые неразобранные цены** того же продавца за ту же услугу —
  разобраны: их сменила новая.
- **Метрики**: снимок `(площадка, csv_import, продавец, дата)` — та же
  дата обновляется.
- **Наша заметка** — в `site_notes` с источником «имя файла»; тот же
  текст у площадки второй раз не пишется.
- **Рабочий список** «‹продавец› · ДД.ММ.ГГГГ», `first_seen` — площадку
  создала эта загрузка.

### 6.6. Повторная загрузка

Тот же файл (отпечаток) с той же датой у того же продавца — открывается
прежняя загрузка, ничего не пишется. Другой файл с той же датой —
снимки дня обновляются, дублей нет. Новая дата — новые снимки; цены,
которые не изменились, — во вкладке «Без изменений».

Замер на копии рабочей базы, полный каталог 01.10.2026: проверка 5 с,
запись 60 с (43 145 новых площадок); повторная выгрузка — 11 с и 40 с.

### 6.7. Каталог: «Обновить в базе», «Добавить новые», фильтры

У каталога запись — двумя кнопками (ADR-044, уточнение 02.10.2026):

| Кнопка | Строки плана | Фильтр |
|---|---|---|
| Обновить в базе | площадки, которые есть в базе (не удалённые, не заблокированные) | нет |
| Добавить новые | новые для базы, в том числе удалённые раньше | да |

Галочки у обеих: **цены** — предложения, рабочая цена, разбор; **метрики**
— снимок DR, трафика, ключей; **описание** — факты карточки §6.4. Без
описания новая площадка заводится с доменом и источником. Площадки
нажатия — в рабочий список загрузки. Каждое нажатие — строка
`result["runs"]`, сводка после записи пересчитывается.

Фильтры — по колонкам выгрузки, значения как в файле:

| Поле | Колонка | Как сравнивается |
|---|---|---|
| Языки | Website languages | любое из, в ячейке несколько через запятую |
| Страна | Country | любое из, в ячейке несколько через запятую (9 020 строк на 01.10.2026) |
| DR | DR | от — до |
| Общий трафик | Monthly Traffic | от — до |
| Органический трафик | Organic traffic | от — до |
| Ключи | Keywords | от — до |
| Цена публикации | Publishing price article, EUR | от — до, евро; у дубля — меньшая |
| Тип ссылки | Link type article | любое из |
| Пометка «реклама» | Advertising mark article | любое из |

Сравнение без учёта регистра. Нет значения при заданном диапазоне — не
проходит. Нет колонки в выгрузке — значение пустое. Строки для фильтров
разбираются при проверке и лежат в кеше 7 дней: счётчик на 45 000
строк — 0,2 с. Замер на копии: «USA и India, DR от 30, dofollow, до
€300» — 5 529 из 43 145; «Обновить в базе» — 15 с, «Добавить новые» на
5 529 — 20 с.

## 7. Выгрузки Ahrefs Batch Analysis — экран «Загрузки» (E1-10)

Тип загрузки «Ahrefs Batch Analysis» (ADR-045); код —
`apps/sites/uploads/ahrefs.py`. Файл — кнопка Export на странице Batch
analysis: UTF-16 с меткой порядка байт, табуляция, все значения в
кавычках (чтение — §6.1). Разметка встроена, продавца нет, страну
выгрузки выбирает человек: в файле её нет.

### 7.1. Колонки

Соответствие проверено на 81 домене (таблица линкбилдинга ↔ выгрузки
`my_source/batch_analysis_2026-10-01_*.csv`).

| Колонка | Все страны (All locations) | Страна |
|---|---|---|
| Target | домен (`companionlink.com/` → `companionlink.com`; адрес с путём — домен и пометка «адрес вместо домена») | так же |
| Mode | `subdomains` или `domain`, иначе ошибка строки: метрики страницы | так же |
| Domain Rating | `site_metrics.dr` | только в `raw` — DR общий |
| Organic / Traffic | `site_metrics.organic_traffic` — общий трафик | `site_country_metrics.organic_traffic` — трафик страны |
| Organic / Total Keywords | `site_metrics.total_keywords` | `site_country_metrics.total_keywords` |
| Organic / Top Countries | «(us, 21101)» → `top_geo` = `us`, `top_geo_traffic` = 21101 | колонки нет |
| Остальные непустые, кроме «#» | `raw` замера: UR, Ahrefs Rank, ключи по позициям, Value, Paid, ref. domains, backlinks, outgoing | так же |

Пусто — «нет данных», `NULL`, а не ноль: у Ahrefs ноль пишется нулём.
Битое число или топ-страна — ошибка строки с номером, строка не пишется.
Дубль домена — первая строка, все строки — в сводку.

### 7.2. Страна выгрузки

Выгрузку «все страны» видно по колонке «Organic / Top Countries» — при
выбранной стране её нет. Выбрана страна, а колонка есть, или «все
страны», а колонки нет, — загрузка «Ошибка» с подсказкой, ничего не
пишется. Трафик топ-региона в региональные данные не пишется (ADR-045).

### 7.3. Запись

- Только к площадкам базы (удалённая — «не в базе»), площадки не
  создаются; домены не из базы — список в сводке.
- Снимок: источник `ahrefs_batch`, без продавца, дата — начало дня даты
  замера. Ключ снимка — площадка (и страна), источник, дата: есть —
  обновляется, нет — создаётся.
- Рабочего списка и разбора нет. Итог — счётчики замеров: новые,
  обновлённые, без изменений.

### 7.4. Повторная загрузка

Тот же файл (отпечаток) с той же датой и страной — открывается прежняя
загрузка. Другой файл той же даты — снимки дня обновляются (так грузят
части по 500 одного дня). Новая дата — новые снимки.

### 7.5. «Домены для Ahrefs»

Домены рабочего списка частями по 500 (лимит Batch Analysis на запуск),
по DR из `v_site_latest` от большего, без удалённых; txt — один домен на
строку, или все части zip. Проверено на копии рабочей базы: список
«Collaborator · 02.10.2026» — 4177 доменов, 9 файлов; первые четыре — с
DR, дальше — новые площадки каталога без метрик.
