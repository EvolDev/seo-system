# E11. Рутина размещений: Collaborator, Google-таблицы, плагин

**Цель эпика.** Убрать ручной перенос данных и ручные сверки между
Collaborator, системой, таблицей «Линкбилдинг» и таблицами барыг. Данные
собирают и сверяют система и плагин, человек проверяет и решает. Около 100
размещений в месяц, ошибки от усталости. Просьба пользователя 08.11.2026:
«чтобы всё свелось к тому, что ты просто проверяешь, что всё корректно и
проверки отрабатывают как надо».

**Зависит от:** E1 · **Блокирует:** —

**Исследование и решения обсуждения** — `docs/specs/browser-plugin.md`:
рабочий порядок пользователя, разметка страниц и ответы сервера Collaborator,
поля API, листы таблиц, пробная сверка от 08.11.

**Принципы.**
- Данные Collaborator берём через официальный API: токен
  `COLLABORATOR_API_KEY`, только чтение, только по кнопке («раз в день что-то
  меняется»). Со страниц — только то, чего в API нет (плагин).
- Записываем только по действию человека и с показом, что изменится.
  Пустое заполняется, а расходящееся решает человек.
- Всё сначала проверяется в отдельной ветке на копии рабочей базы и втором
  сервере (:8002). В рабочую систему переносим после «ок» пользователя.
- Браузер — только Chrome.

**Состояние (09.11.2026).** E11-01 сделана и в рабочей базе (ADR-079,
ADR-080). Остальные задачи — на потом: сначала инфраструктура и выкладка на
прод (пользователь, 09.11.2026).

## E11-02 · Подбор анкоров: стратегии, экран выбора, Claude Code по заданию
**Размер:** M · **Зависимости:** E3-05 · **Фаза:** 2

**Зачем.** Рекомендации по долям (ADR-059) часто не подходят: они не видят
тематику площадки. Подбор пачками по 10 площадок уходит в чат, и каждая
сессия заново собирает выгрузку базы, страницу и проверки (папки Hans
`anchor_selection_*` в convertio-ai-editor). Стратегия меняется: за октябрь
их было четыре.

**Что делаем.**
- Стратегия подбора — запись в «Справочники → Анкоры»: регион, состав
  (например, 5 прямых + 1 брендовый + 1 общий + 3 фразы или 3+2+5),
  диапазон позиций, приоритеты и текст для нейронки обычными словами.
  Подбор помнит, по какой стратегии сделан.
- «Подобрать анкоры» у отмеченных строк «Размещений» создаёт задание.
  Помощник на компьютере пользователя запускает на каждое задание Claude
  Code без окна: `claude -p`, `--no-session-persistence`, `--tools` — только
  WebFetch и WebSearch, ответ по `--json-schema`. Данные даёт система.
- Страница подбора: кандидаты по релевантности, «как ляжет в тематику».
  Щелчок ставит анкор в размещение (ключ, текст, вид — как в ADR-069),
  повторный щелчок снимает. Выбранное понижает повторы у остальных
  площадок.
- Ответ нейронки проверяет код: ключ из списка региона, позиция в
  диапазоне, фраза содержит ключ, бренд по виду, состав сходится, нет
  повторов.
- Исполнитель сменный: Codex (`codex exec`), позже ключ API (E4-01).

**Не входит:** блок «Рекомендуем» в панели (перевести или убрать — после).

## E11-03 · Google-таблицы: скрипт в аккаунте, зеркало «Линкбилдинга»
**Размер:** M · **Зависимости:** E1-06 · **Фаза:** 2

**Зачем.** Лист «Размещения» сейчас ведётся руками: шаблон NOV-26 →
«Скопировать» → поиск строки → вставка. Лист читает начальство, и это
запасная копия пользователя на случай поломки системы.

**Что делаем.**
- Скрипт Google (Apps Script) в аккаунте пользователя: веб-приложение
  «выполнять от моего имени», секрет — в `.env`. Проект в Google Cloud не
  нужен. В скрипте нет логики, только чтение и запись по командам системы.
- Зеркало листа — по кнопке и по расписанию: полная перезапись по
  раскладке NOV-26, месяц берётся из даты «Опубликовано». Перед записью —
  сверка с прошлой записью: правки руками в листе показываются и без
  вопроса не затираются. Импорт таблицы (E1-04) остаётся обратной дорогой
  на случай поломки системы.
- Сначала — на копии таблицы.

## E11-04 · Барыги: таблица по шаблону, защита колонок, заявки и сверка
**Размер:** M · **Зависимости:** E11-03 · **Фаза:** 2

**Зачем.** У каждого барыги своя таблица со своим порядком колонок, заявки
вставляются руками, барыга может поменять зафиксированную цену. Все таблицы
барыг принадлежат пользователю.

**Что делаем.**
- «Создать таблицу для барыги» в карточке продавца — одна раскладка для
  всех:
  - вкладки заказов, оплат и задания;
  - список статусов;
  - защищённые колонки: барыга правит только Status, черновик и Live link;
  - доступ на почту барыги.
- Новые размещения «Заявка отправлена» дописываются в его таблицу сами.
- Сверка с таблицей барыги:
  - цена, анкор и ссылка — против зафиксированного;
  - Published и Live link → «готовы к закрытию»;
  - оплаты — против счетов (E1-14).
- Открыт вопрос: переводить ли нынешних барыг на новые таблицы.

## E11-05 · Плагин Chrome: проверка статьи, индекс в Google, подсказки на Collaborator
**Размер:** M · **Зависимости:** E11-01 · **Фаза:** 2

**Зачем.** Анкоры надо проверять не только в Details, но и в самой
опубликованной статье. Индекс сейчас проверяется руками через `site:`, а
подтверждать сделку можно только после индекса — до автоприёма.

**Что делаем.** На основе `browser-extension/` (ADR-054):
- Проверка открытой статьи в боковой панели Chrome по каждой ссылке на
  convertio.co: текст анкора, адрес, rel (nofollow, sponsored, ugc), место
  от начала текста (ADR-032), лишние ссылки. Сверка — со ссылками
  размещения в системе. Результат идёт в систему.
- Индекс через Google `site:адрес` из браузера пользователя.
- На страницах Collaborator: таймер автоприёма и индекс самого
  Collaborator, бесплатный анонс (этого нет в API), подсказки «в индексе —
  можно подтверждать» и «нет в индексе N дней — на доработку».
- Адрес системы задаётся в настройке плагина: 8000, 8002, потом сервер.

## E11-06 · Плагин: корзина Collaborator — анкоры из системы и правила корзины
**Размер:** S · **Зависимости:** E11-02, E11-05 · **Фаза:** 2

**Что делаем.**
- В корзине у Links и Anchors — ✓ или ✗ против ссылок размещения и кнопка
  «Подставить из системы». Поля React: значение — через нативный сеттер и
  событие `input`.
- Правила корзины из `source/flow.txt`:
  - проект Convertio;
  - «пишет владелец», если написание стоит не больше 50 €;
  - анонс дешевле 100 € — берём, дороже — согласовать;
  - особые тематики — не берём.

## E11-07 · Проверка индексации по расписанию: сверить и включить
**Размер:** S · **Зависимости:** E2-03 · **Фаза:** 2

**Что делаем.** Сверить ответы проверки (Serper, ADR-042) с ручными
отметками на ~100 последних статьях. Если совпадают — включить
`INDEXATION_SCHEDULE`. За октябрь Serper обошёлся в 15 центов. Итог
проверки показывать в сверке и подсказках плагина.
