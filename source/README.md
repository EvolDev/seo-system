# Исходные материалы

Первичные документы, на которых основаны доменные правила. Положены в
пакет, чтобы он был самодостаточным: при работе над ТЗ не придётся
искать их по другим папкам.

| Файл | Что это | Где используется |
|---|---|---|
| `flow.txt` | текущий ручной процесс, описания полей таблицы | `04-DOMAIN-RULES.md`, `01-GLOSSARY.md`, `12-IMPORT-MAPPING.md` |
| `Задание_для_владельца_площадки.txt` | ТЗ для площадки: 17 требований к статье и правила интеграции анкора | `04-DOMAIN-RULES.md` §3, `05-CONTENT-SYSTEM.md`, E5-02, E7-01 |
| `audit-system-prompt.md` | системный промпт SEO-аудитора — снапшот от 23.09.2026, источник правды — инструкции Project | `04-DOMAIN-RULES.md`, `11-PROMPTS.md` §P1, E4-04 |
| `page_types_distribution.csv` | целевые доли по типам страниц | фоновый контекст, сейчас не применяется (Q10) |

**Важно про приоритет версий.** Эти файлы — источник, а не
спецификация. Формализованная версия правил живёт в
`04-DOMAIN-RULES.md` и в таблице `rules`. При расхождении верна
формализованная версия, а исходник правится следом.

Не вошло в пакет намеренно: полные выгрузки базы линкбилдинга и
распределения анкоров. Они объёмные, меняются, и их место — в импорте
(E1-04), а не в документации. Все расчёты по ним зафиксированы в
`10-BASELINE-STATS.md`, а разбор колонок — в `12-IMPORT-MAPPING.md`.
